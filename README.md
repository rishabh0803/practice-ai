# 🧠 practice-ai

This is my personal AI/ML practice repo — a place where I can try out example codes, experiment with different libraries/frameworks, take notes, and generally mess around while learning.  
Everything stays in one place to keep things simple.

---

## 📂 Structure & Purpose

This is how I’ve organized the repo (subject to evolve):


```
practice-ai/
├── coaching/
│   └── ml-ai/
│       ├── eg0001.c                
│       ├── eg0002.py
│       ├── frameworks/            
│       │   ├── rikai/
│       └── playground/             # Adhoc/testing code, quick experiments
├── research-notes/                 # Notes, theory, paper summaries, etc.
├── ai-experiments/                # Projects or explorations not part of coaching
├── datasets/                       # Sample/test datasets (only if needed)
├── README.md
└── .gitignore

````

## 🧩 Folder Meaning (for me)

- **`coaching/ml-ai/`**  
  This is the *main* folder for structured practice. Each file like `eg0001.c`, `eg0002.py` is a short exercise. Good for building basics.

- **`frameworks/`** (inside `ml-ai/`)  
  For organizing code by library — e.g., creating own framework

- **`playground/`**  
  Unstructured experiments — random ideas, code from YouTube videos, debugging small stuff, etc.

- **`research-notes/`**  
  Notes from books, courses, blogs, or research papers. Can be markdown files or Jupyter Notebooks.

- **`ai-experiments/`**  
  Mini-projects or tasks that are not part of coaching. Eg: building a chatbot, image classifier, etc.

- **`datasets/`**  
  For dumping small datasets I may need to run local tests or examples. Keep this lightweight.
